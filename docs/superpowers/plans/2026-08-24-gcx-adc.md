# gcx ADC por cuenta — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que `gcx use` cambie también las Application Default Credentials (almacén por cuenta + parche de `quota_project_id`), con subcomando `gcx adc` para emitirlas y línea de estado con aviso en `gcx who`.

**Architecture:** Todo vive en `config/zsh/gcp.zsh` como helpers `_gcp_adc_*` en una sección nueva, siguiendo el patrón del archivo: helpers pequeños, escritura atómica vía temporal con PID + `mv`, mensajes leídos de gcloud. El almacén es `${CLOUDSDK_CONFIG:-$HOME/.config/gcloud}/adc/<cuenta-sanitizada>.json` (700/600). La única función interactiva (`_gcp_adc_login`) envuelve `gcloud auth application-default login` y no se testea.

**Tech Stack:** zsh, jq (degrada a no-op si falta), arnés de tests propio de `gcp.test.zsh` (`assert_eq`/`assert_contains`, stubs de `gcloud` con `unfunction`).

**Spec:** `docs/superpowers/specs/2026-08-24-gcx-adc-design.md`

## Global Constraints

- Rama de trabajo: `feat/gcp-adc-switch` (ya existe; nunca commitear a `main`).
- Commits: `<tipo>(gcp): <asunto>` — asunto en minúscula, imperativo, sin punto, ≤72 chars. El hook `commit-msg` los valida. **Nunca encadenar nada detrás de un `git commit` en la misma invocación**; verificar con `git log --oneline -1` en llamada aparte.
- Sintaxis zsh: validar con `zsh -n config/zsh/gcp.zsh` — **shellcheck no vale para zsh**.
- Los tests corren **sin gcloud, sin red, sin fzf**: `zsh config/zsh/gcp.test.zsh`. Mantener esa propiedad (stubs con `unfunction` al cerrar cada bloque).
- Ningún mensaje de estado hardcodea cuenta ni proyecto: todo se lee de gcloud o de los archivos reales.
- Credenciales jamás dentro del repo. El almacén ADC va en el HOME del usuario.
- Escrituras sobre archivos de credenciales: `umask 077` + temporal `.tmp.$$` en el mismo directorio + `mv -f` (atómico).
- Permisos en tests: comprobar con `ls -l | cut -c1-10` (portable macOS/Linux; `stat` difiere de flags entre BSD y GNU).
- El CHANGELOG se regenera con `./scripts/changelog.sh` **al final, en su propio commit** que no toca nada más.

- [ ] **Step 3: Implementación.**

```zsh
# Parchea quota_project_id en un archivo ADC. El quota project es de la
# config, no de la cuenta: dos configs de la misma cuenta comparten ADC pero
# no quota. Temporal con umask 077 + mv en el mismo directorio: la ADC nunca
# queda a medias ni legible por otros usuarios, ni un instante.
_gcp_adc_set_quota() {
    local file="$1" project="$2" tmp
    [[ -n "$project" && -r "$file" ]] || return 0
    command -v jq >/dev/null 2>&1 || return 0
    tmp="${file}.tmp.$$"
    if ( umask 077; jq --arg p "$project" '.quota_project_id = $p' "$file" >"$tmp" 2>/dev/null ); then
        mv -f "$tmp" "$file"
    else
        rm -f "$tmp"
        return 1
    fi
}

# Guarda la ADC viva como la ADC de <cuenta>. La usa `gcx adc` tras el login.
_gcp_adc_save() {
    local account="$1" live store tmp
    live="$(_gcp_adc_live_path)"
    [[ -n "$account" && -r "$live" ]] || return 1
    store="$(_gcp_adc_store_path "$account")"
    mkdir -p "$(_gcp_adc_dir)"
    chmod 700 "$(_gcp_adc_dir)"
    tmp="${store}.tmp.$$"
    ( umask 077; cp "$live" "$tmp" ) && mv -f "$tmp" "$store"
}
```

```zsh
# Instala la ADC guardada de <cuenta> como ADC viva y ajusta su quota project
# al proyecto de la config. Con cuenta vacía calla (el fallo visible es de la
# config); sin ADC guardada avisa y no toca nada.
_gcp_adc_install() {
    local account="$1" project="$2" store live tmp
    [[ -n "$account" ]] || return 0
    store="$(_gcp_adc_store_path "$account")"
    live="$(_gcp_adc_live_path)"
    if [[ ! -r "$store" ]]; then
        print -r -- "  ⚠ no hay ADC guardadas para $account" >&2
        print -r -- "    emítelas una vez con: gcx adc" >&2
        return 1
    fi
    mkdir -p "${live:h}"
    tmp="${live}.tmp.$$"
    { ( umask 077; cp "$store" "$tmp" ) && mv -f "$tmp" "$live"; } || {
        rm -f "$tmp"
        print -r -- "  ✗ no se pudo instalar la ADC de $account" >&2
        return 1
    }
    _gcp_adc_set_quota "$live" "$project"
}
```
